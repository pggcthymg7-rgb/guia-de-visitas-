# Guia de Visitas Imobiliárias (`guia-de-visitas-`)

Aplicação web interativa para roteiros de visitas imobiliárias, geração de Guia em PDF e acompanhamento presencial de clientes (individual ou em dupla com cruzamento automático de avaliações e observações), projetada para execução no **GitHub Pages**.

## Arquivos de Especificação e Engenharia neste Repositório

- **[`PROMPT_ANTIGRAVITY.md`](./PROMPT_ANTIGRAVITY.md):** Prompt mestre pronto para copiar e colar no Google Antigravity para construção completa, validação e deploy imediato do Web App.
- **[`DESIGN.md`](./DESIGN.md):** Sistema de design oficial inspirado na referência editorial Airtable (*Parchment Cream `#faf5e8`*, *Onyx `#181d26`*, tipografia *Haas Groot Disp / Roboto Slab 900* + *Haas / Inter*, e *Color-Coded Chapter Cards*).
- **[`ARCHITECTURE_AND_QA_SPEC.md`](./ARCHITECTURE_AND_QA_SPEC.md):** Especificação técnica de arquitetura (DDD, Arquitetura Hexagonal, sincronização para 1 ou 2 visitantes com *Fencing Tokens* e *Idempotency Keys*) e matriz de qualidade/testes (ISO/IEC 25010:2023, ISO/IEC/IEEE 29119, prevenção de crash WebKit/Jetsam no iOS e *Zero Data Loss*).
